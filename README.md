A personal landing page created using NextJS and TailwindCSS. Contains an integration with Spotify to display a user's current song they are listening to.

## Environment Variables
- `NEXT_PUBLIC_SPOTIFY_REFRESH_TOKEN` - Refresh token for the linked Spotify Account
- `NEXT_PUBLIC_SPOTIFY_CLIENT_SECRET` - Spotify Application Client Secret
- `NEXT_PUBLIC_SPOTIFY_CLIENT_ID` - Spotify Application Client ID

## Development

To run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result
